# Licznik czasu pracy

Gotowa prosta strona internetowa do liczenia czasu pracy i zarobków.

## Funkcje
- START rozpoczyna liczenie czasu.
- STOP I ZAPISZ kończy zmianę i dodaje ją do historii.
- Stawka: 30 zł za godzinę.
- Automatyczne liczenie zarobku.
- Miesięczne podsumowanie czasu i kwoty.
- Wybór miesiąca.
- Dane pozostają zapisane po odświeżeniu lub zamknięciu strony.
- Możliwość usuwania pojedynczych wpisów i wyczyszczenia całej historii.

## Uruchomienie
Otwórz plik `index.html` w przeglądarce.

Możesz też wrzucić sam plik `index.html` do repozytorium GitHub Pages.
