REDLINE PERFORMANCE — GitHub Pages

Pliki:
- index.html — strona główna
- o-firmie.html — informacje o firmie
- cennik.html — cennik
- eventy.html — wydarzenia
- rekrutacja.html — formularz rekrutacyjny
- style.css — wygląd całej strony
- script.js — menu mobilne + obsługa formularza

JAK WRZUCIĆ NA GITHUB:
1. Wejdź do repozytorium.
2. Zakładka Code.
3. Add file -> Upload files.
4. Wrzuć wszystkie pliki z tego folderu do głównego katalogu repozytorium.
5. Commit changes.
6. Po około minucie odśwież GitHub Pages.

WAŻNE:
GitHub Pages jest hostingiem statycznym, więc sam HTML nie zapisze aplikacji kandydatów.
Formularz jest przygotowany wizualnie. Można podłączyć:
- Formspree,
- Google Forms,
- własny backend/API.

Najbezpieczniej NIE wklejać bezpośrednio webhooka Discord do publicznego pliku JavaScript,
bo każdy odwiedzający może go podejrzeć.
